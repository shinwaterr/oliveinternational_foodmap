# 올리브인터내셔널 맛지도

회사(그레이츠강남 14층, 강남역 8번 출구 쪽) 근처 맛집 70곳 지도, 오늘 뭐 먹지, 랜덤 런치밋.

- **웹 맛지도 (런치밋 포함)**: https://shinwaterr.github.io/oliveinternational_foodmap/ (`index.html`)
- **웹 맛지도 기본형 (런치밋 탭 없음)**: https://shinwaterr.github.io/oliveinternational_foodmap/no-lunchmeet/ (`no-lunchmeet/index.html`)
- **슬랙 앱**: [`slack-app/`](slack-app/) — `/matjip` 맛집 찾기, `/mwomeokji` 오늘 뭐 먹지, `/lunchmeet` 랜덤 런치밋. 설치 방법은 [`slack-app/README.md`](slack-app/README.md)

맛집 정보 출처: 노션 '맛지도 > 강남 맛집 리스트' (피플팀 추천). 위치·출구 좌표는 카카오맵 기준이며, 도보 시간과 출구 거리는 직선거리로 계산한 추정치입니다.
