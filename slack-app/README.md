# 올리브 맛지도 슬랙 앱

회사(그레이츠강남 14층, 강남역 8번 출구 쪽) 근처 맛집 70곳을 슬랙에서 바로 찾고, 점심 메뉴를 무작위로 뽑고, 다른 팀과 **랜덤 런치밋**을 운영하는 슬랙 앱입니다.

## 슬랙에서 쓰는 명령어

| 명령어 | 하는 일 | 예시 |
|---|---|---|
| `/matjip` | 맛집 찾기. 비워 두면 메뉴 버튼이 나오고, 메뉴나 가게 이름을 적으면 바로 찾아줘요. 회사에서 가까운 순, 6곳씩 넘겨 봐요. | `/matjip 일식`, `/matjip 텐동` |
| `/mwomeokji` | 오늘 뭐 먹지? 한 곳을 무작위로 추천. 다시 뽑기, 채널에 공유 가능 | `/mwomeokji`, `/mwomeokji 중식` |
| `/lunchmeet` | 랜덤 런치밋 신청·취소·현황 보기 | `/lunchmeet` |

- 모든 맛집 카드에는 **🧭 길안내** 버튼이 있어요. 누르면 회사 → 가게 카카오맵 도보 길찾기가 열려요.
- 명령어 결과는 **나에게만** 보여요. 채널에 공유하려면 `📣 채널에 공유` 버튼을 눌러요.
- 슬랙 명령어는 영어로만 안정적으로 등록돼서 영문 이름을 썼어요. (matjip = 맛집, mwomeokji = 뭐먹지)

### 랜덤 런치밋 흐름
1. **운영자**가 `/lunchmeet` → `📣 모집 공지 올리기` → 런치밋 채널에 신청 버튼이 달린 공지가 올라가요.
2. **직원**은 공지의 `🙋 참여 신청하기`(또는 `/lunchmeet`)를 눌러 소속 팀과 선호 메뉴(선택, 최대 3개)를 적어요.
3. **운영자**가 `🎲 조 편성 후 게시`를 누르면
   - 같은 팀은 되도록 다른 조로, 3~4명씩 자동 편성
   - 조원 선호 메뉴에 맞춰 도보 10분 이내 식당 배정 (카페·회식 장소 제외, 조끼리 겹치지 않음)
   - 런치밋 채널에 결과가 올라가고, 참여자 각자에게 "우리 조" 메시지가 가요.
4. 회차 날짜는 기본이 **다음 금요일**이고, 운영자가 `📅 회차 날짜 변경`으로 바꿀 수 있어요.

## 설치 순서 (처음 한 번)

> 슬랙 앱을 워크스페이스에 설치하려면 **슬랙 관리자 승인**이 필요할 수 있어요.

### 1. 준비물
- **Node.js 18 이상** (https://nodejs.org 에서 LTS 버전 설치)
- 앱을 켜 둘 컴퓨터 또는 서버 (아래 6번 참고)

### 2. 슬랙 앱 만들기
1. https://api.slack.com/apps 에 접속 → **Create New App** → **From a manifest**
2. 회사 워크스페이스 선택
3. 이 폴더의 `manifest.json` 내용을 통째로 붙여넣기 (JSON 탭) → **Create**

### 3. 토큰 두 개 받기
1. **앱 토큰 (xapp-)**: 왼쪽 메뉴 **Basic Information** → 아래쪽 **App-Level Tokens** → **Generate Token and Scopes** → 이름 아무거나, 권한 `connections:write` 추가 → 생성된 `xapp-...` 복사
2. **봇 토큰 (xoxb-)**: 왼쪽 메뉴 **Install App** → **Install to Workspace** → 허용 → **OAuth & Permissions** 에서 `Bot User OAuth Token`(`xoxb-...`) 복사

> ⚠️ 두 토큰은 비밀번호와 같아요. 메신저·문서에 붙여넣거나 깃허브에 올리지 마세요.

### 4. 설정 파일 만들기
이 폴더에서 `.env.example` 을 복사해 `.env` 로 이름을 바꾸고 값을 채워요.

```
SLACK_BOT_TOKEN=xoxb-…            # 3-2에서 복사
SLACK_APP_TOKEN=xapp-…            # 3-1에서 복사
ADMIN_USER_IDS=U0XXXXXXX          # 런치밋 운영자 멤버 ID (여러 명이면 쉼표로)
LUNCHMEET_CHANNEL=C0XXXXXXX       # 모집 공지·결과를 올릴 채널 ID (비워두면 버튼 누른 채널)
```
- **멤버 ID**: 슬랙에서 내 프로필 → `⋮` → **멤버 ID 복사**
- **채널 ID**: 채널 이름 클릭 → 맨 아래 **채널 ID**
- 비공개 채널에 올리려면 그 채널에 `/invite @맛지도` 로 앱을 초대해야 해요.

### 5. 실행
터미널(명령 프롬프트)에서 이 폴더로 이동한 뒤:
```
npm install
npm start
```
`🍱 맛지도 슬랙 앱이 켜졌어요` 가 보이면 성공! 슬랙에서 `/matjip` 을 입력해 보세요.

### 6. 계속 켜 두기
이 앱은 **켜 둔 컴퓨터에서만** 동작해요. 컴퓨터를 끄면 명령어에 응답하지 않아요.
- 공개 서버 주소가 필요 없는 방식(Socket Mode)이라, 사내 서버나 항상 켜 두는 PC 한 대면 충분해요.
- 런치밋 신청 내용은 `data/lunchmeet.json` 파일에 저장돼요. 서버를 옮길 때 이 파일도 같이 옮기세요.

## 맛집 정보 고치기
`src/restaurants.json` 에 70곳이 들어 있어요. 이름(`name`), 카테고리(`category`), 추천 메뉴(`menu`), 참고 문구(`note`) 등을 고친 뒤 앱을 다시 켜면 반영돼요.
- 카테고리 값: `한식-일반`, `한식-국물(찌개 포함)`, `중식`, `일식`, `양식`, `분식`, `샐러드&샌드위치`, `버거`, `기타`, `카페`, `저녁회식장소추천` (노션 '강남 맛집 리스트'와 같아요)
- `walkMin`(도보 분)은 회사에서 직선거리 × 1.3 으로 계산한 추정치, `exitMeters`는 가장 가까운 강남역 출구에서의 직선거리예요.

## 웹 버전 (저장소 맨 바깥 `index.html`)
슬랙 밖에서 쓰는 지도 화면이에요. 지도·맛집 카드·길안내·오늘 뭐 먹지가 들어 있고, 런치밋 탭은 슬랙 `/lunchmeet` 으로 안내해요.
- 주소: https://shinwaterr.github.io/oliveinternational_foodmap/
- 휴대폰에서 이 주소를 열고 **홈 화면에 추가**하면 앱처럼 쓸 수 있어요.
